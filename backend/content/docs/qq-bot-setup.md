# QQ 机器人配置

> 平台不代申请 QQ 机器人，也不托管机器人进程。申请在 QQ 开放平台完成，机器人运行由外部 AstrBot 负责。

## 1. 去 QQ 开放平台创建应用

1. 打开 QQ 开放平台，创建一个机器人应用。
2. 在应用详情中获取 **AppID** 和 **AppSecret**。
3. 按开放平台要求配置机器人回调/事件订阅地址。
4. 将机器人进程部署在班级可访问的服务器上，并由 AstrBot 负责运行。

> 文档中不要填写真实 AppID、AppSecret 或服务器 IP。

## 2. 在班级设置中保存

进入「班级设置 → QQ 机器人」，填写：

| 字段 | 说明 |
|---|---|
| AppID | 开放平台应用详情中的 AppID |
| AppSecret | 开放平台的应用密钥，保存后不再完整显示 |
| 回调地址 | 外部机器人服务接收事件的地址 |
| 启用 | 是否允许该班级使用机器人绑定 |

首次保存必须填写 AppSecret。之后如需修改其他字段，Secret 留空表示不修改。

## 3. 测试连接

点击「测试连接」后，平台会用保存的 AppID/AppSecret 调用 QQ 的 `getAppAccessToken` 接口：

- 成功：返回 `ok=true` 和 `expires_in`。
- 失败：返回 `ok=false`，并给出 QQ 错误码/描述。
- 超时：最多等待 8 秒，不会把请求体或 Secret 返回给前端。

## 4. 常见问题

- **保存提示未配置 BOT_SECRET_KEY**：联系运维在服务端环境变量中配置 32 字节 base64 的 Fernet 密钥。
- **测试失败但配置正确**：检查服务器出网、开放平台应用状态和回调地址。
- **Secret 忘记了**：重新在开放平台生成后，在班级设置中重新保存；平台无法找回明文。
