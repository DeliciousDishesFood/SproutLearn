# QQ 机器人配置

> 平台不代申请 QQ 机器人。请先在 QQ 开放平台创建机器人应用；AppID/AppSecret 由服务端环境变量托管，不进入班级表、不回显、不写日志。

## 1. 在 QQ 开放平台申请

1. 打开 QQ 开放平台，创建机器人应用。
2. 获取 AppID 和 AppSecret。
3. 按开放平台要求配置事件订阅/回调。
4. 联系运维把 AppID/AppSecret 写入服务端环境变量 `QQ_BOT_APP_ID` / `QQ_BOT_APP_SECRET`。

> 文档中不填写真实 AppID、AppSecret 或服务器 IP。

## 2. 班级设置

进入「班级设置 → QQ 机器人」，填写/确认：

| 字段 | 说明 |
|---|---|
| AppID | 仅用于展示/核对，实际凭证读服务端环境变量 |
| 回调地址 | 外部事件接收地址 |
| 启用 | 是否启用本班机器人 |
| 绑定/通知/查询权限 | 控制学生绑定、作业通知、作业/成绩查询 |

AppSecret 不由页面保存；页面只显示“密钥由服务端环境变量托管”。

## 3. 群绑定

1. 教师在班级设置点击“生成群绑定码”，得到 10 分钟有效的一次性码。
2. 在 QQ 群里 @机器人，发送：`绑定群 <8位群绑定码>`。
3. 机器人回复“本群已绑定班级 X”，群码不落库。

## 4. 学生命令

| 命令 | 说明 |
|---|---|
| `绑定 <8位数字>` | 绑定学号 |
| `作业` | 查看待做作业（老师开启查询时） |
| `成绩` | 查看最近成绩（老师开启查询时） |
| `解绑` | 解除绑定 |
| `帮助` | 命令列表 |

## 5. 通知与测试

- 发布作业后，若班级已绑定群且开启通知，群内收到开始/截止时间。
- 截止前 2 小时 worker 只提醒一次；未交名单会列出，@ 能力不支持时降级为名单。
- 点击“测试连接”调用 QQ `getAppAccessToken`，8 秒超时；只返回 `ok/message/expires_in`，不返回 Secret 或请求体。

## 6. 常见问题

- **测试失败**：检查服务端出网、`QQ_BOT_ENABLED`、AppID/AppSecret 环境变量和开放平台状态。
- **群没收到通知**：确认群已绑定、班级通知开关开启、worker 服务在运行。
- **Secret 轮换**：只需更新服务端环境变量并重启 api/bot-worker，不需要在页面重填。
