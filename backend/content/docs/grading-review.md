# 判分与复核

## 1. 判分流程

学生提交后，平台按题型判分：

- 单选、多选、判断：确定性判分。
- 填空、简答：优先使用判分内核；无法确定时标记为待复核。
- 低置信度或判分服务不可用时，记录 `needs_review`，不阻塞学生提交。

## 2. 教师复核

进入试卷的作答列表，打开待复核作答：

1. 查看学生答案、参考答案和判分理由。
2. 修改得分并填写复核意见。
3. 保存后成绩立即更新，历史复核记录保留。

已发布试卷引用的题目只允许修改解析，避免历史成绩漂移。

## 3. 状态说明

| 状态 | 含义 |
|---|---|
| submitted | 学生已提交，等待判分/复核 |
| graded | 已完成判分 |
| needs_review | 存在需要教师确认的答案 |

## 4. 成绩与经验

- 学生提交考试 +50 经验，提交作业 +20 经验（以配置表为准）。
- 练习按答对题的难度发经验，单日有封顶。
- 复核改分只影响成绩，不重复发放已发经验。

> 复核是纠正判分的唯一入口；不要在数据库直接改分，避免流水与统计不一致。
