# 题库导入

## 1. 支持格式

- JSON：题目对象数组。
- XLSX / XLS：第一行表头，从第二行开始读取。
- CSV：UTF-8 编码，第一行表头。

一次最多 500 题，文件不超过 10 MB。

## 2. 必填字段

| 字段 | 说明 |
|---|---|
| type | `single` / `multiple` / `judge` / `blank` / `short` |
| stem | 题干 |
| answer | 答案；选择题用选项字母或数组 |

可选字段：`options`、`analysis`、`knowledge_tag`、`difficulty`。

## 3. 预览与提交

1. 上传文件，先调用预览接口；预览不会写库。
2. 检查逐行错误；有错误时修正后重新上传。
3. 提交预览 token 或直接提交文件，题目以 draft 状态入库。
4. 可在导入时选择题库；不选则自动创建「导入题库-日期」。

```json
[
  {
    "type": "single",
    "stem": "TCP 属于哪一层协议？",
    "options": ["应用层", "传输层", "网络层", "链路层"],
    "answer": "B",
    "difficulty": "easy"
  }
]
```

## 4. 常见错误

- **42203**：缺少列或类型不符，按预览中的行号修正。
- **41302**：文件超过 10 MB 或题目超过 500 道。
- **41501**：扩展名不在白名单。

> 导入不会覆盖已有题目；重复导入会产生新题，请先预览确认。
