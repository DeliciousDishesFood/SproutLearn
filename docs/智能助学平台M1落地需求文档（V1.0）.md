## 4. 全局契约（✅ 已裁决）

### 4.1 统一响应体

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "request_id": "8f3c1a2b-...",
  "timestamp": "2026-11-07 18:40:00"
}
```

- `code`：业务码，0 为成功；非 0 见 4.2。
- `data`：成功时为业务数据；失败时为 `null`（参数校验失败时为错误字段明细）。
- 分页统一结构：

```json
{ "total": 12, "page": 1, "page_size": 10, "list": [] }
```

- 每个响应必须带 `X-Request-Id` 响应头，与 `request_id` 一致。

### 4.2 错误码枚举（唯一清单，禁止新增未登记码）

| code | HTTP | 含义 | 触发场景 |
|---|---|---|---|
| 0 | 200 | 成功 | — |
| 40001 | 422 | 参数校验失败 | 缺失/类型错误/长度越界 |
| 40101 | 401 | 未登录 | 缺少 Authorization |
| 40102 | 401 | 登录已过期 | 会话不存在或空闲超时 |
| 40103 | 401 | 账号或密码错误 | 登录失败（统一文案，不区分账号是否存在） |

### 4.3 全局异常处理器（代码基线）

```python
# app/exceptions.py
class AppException(Exception):
    def __init__(self, code: str | int, message: str, http_status: int = 400, data=None):
        self.code, self.message, self.http_status, self.data = code, message, http_status, data

# app/utils/response.py
def success(data=None, message="ok") -> dict:
    return {"code": 0, "message": message, "data": data,
            "request_id": get_request_id(), "timestamp": now_str()}

# app/main.py
@app.exception_handler(AppException)
async def app_exception_handler(request, exc: AppException):
    return JSONResponse(status_code=exc.http_status,
        content={"code": exc.code, "message": exc.message, "data": exc.data,
                 "request_id": get_request_id(), "timestamp": now_str()})

@app.exception_handler(RequestValidationError)
async def validation_handler(request, exc):
    return JSONResponse(status_code=422, content={
        "code": 40001, "message": "参数校验失败", "data": exc.errors(),
        "request_id": get_request_id(), "timestamp": now_str()})

@app.exception_handler(Exception)
async def global_handler(request, exc):
    logger.error("未捕获异常", exc_info=True)
    return JSONResponse(status_code=500, content={
        "code": 50001, "message": "服务器内部错误", "data": None,
        "request_id": get_request_id(), "timestamp": now_str()})
```

### 4.4 鉴权与会话

**JWT Payload（HS256，`SECRET_KEY` 来自环境变量）：**

```json
{
  "sub": "12",
  "role": "teacher",
  "class_id": null,
  "iat": 1794000000,
  "exp": 1794000000,
  "jti": "b7c1e2..."
}
```

| 字段 | 说明 |
|---|---|
| sub | 用户 ID（教师或学生，字符串） |
| role | 角色枚举：`teacher` / `student` |
| class_id | 学生必填（所属班级）；教师为 null |
| jti | 会话唯一 ID，用于 Redis 会话键与登出吊销 |
| exp | `ACCESS_TOKEN_MINUTES`（默认 720 分钟，12 小时） |

**会话机制（双保险）：**

1. 登录签发 JWT，同时写 Redis `session:{jti}` → `{"user_id":..,"role":..,"class_id":..}`，TTL = `SESSION_IDLE_MINUTES`（30 分钟）。
2. 每次鉴权：先校验 JWT 签名与过期 → 再读 `session:{jti}`；键不存在 → 返回 `40102 登录已过期`。
3. 校验通过后刷新该键 TTL（滑动过期）。
4. 登出：删除 `session:{jti}`，并把 `jwt:blacklist:{jti}` 写入剩余有效期（防止旧 token 复用）。
5. 角色不匹配 → `40301`；学生访问非本班资源 → `40302`。

**鉴权矩阵：**

| 接口组 | 匿名 | 教师 | 学生 |
|---|---|---|---|
| 健康检查 | ✅ | ✅ | ✅ |
| 教师注册/登录 | ✅ | — | — |
| 学生加入 | ✅ | — | — |
| 学生登录 | ✅ | — | — |
| 班级管理（创建/邀请码/学生列表） | ❌ | ✅ 仅本班 | ❌ |
| 知识库上传/列表/详情/切片 | ❌ | ✅ 仅本班 | ❌ |
| 绑定码生成 | ❌ | ❌ | ✅ 本人 |
| 绑定回调（机器人） | ❌（需 `X-Bot-Secret`） | — | — |
| 当前用户信息 | ❌ | ✅ | ✅ |

**数据库层越权防护（AC 强制项）：**

- 所有仓储查询必须接收 `scope_class_id` 参数（来自 JWT），禁止裸 `select()` 直查跨班数据。
- `BaseRepository.scoped(class_id)` 统一注入过滤条件；新增仓储方法若缺少该参数，评审即打回。
- 外键 + 唯一约束兜底（见第 5 章）。

### 5.16 数据隔离的 DB 层落地

1. 所有查询入口必须带 `class_id`；仓储层封装，禁止 service 直接调用 `db.query(Model)`。

## 6. Redis Key 设计（✅ 已裁决）

| 用途 | Key 格式 | 类型 | TTL | 说明 |
|---|---|---|---|---|
| 登录会话 | `session:{jti}` | STRING(JSON) | `SESSION_IDLE_MINUTES`*60，滑动刷新 | 存 user_id/role/class_id |
| 登出黑名单 | `jwt:blacklist:{jti}` | STRING | JWT 剩余有效期 | 防旧 token 复用 |
| 登录失败计数 | `login:fail:{account}` | STRING(int) | `RATE_LIMIT_LOGIN` 窗口 | 教师 `{account}`=小写登录账号；学生 `{account}`=`{class_code}:{student_no}` |
| 登录限流 | `rate:login:{ip}` | STRING(int) | 窗口 | 固定窗口计数 |
| 加入班级限流 | `rate:join:{ip}` | STRING(int) | 窗口 | 防批量试探邀请码 |
| 邀请码重置锁 | `rate:invite:reset:{class_id}` | STRING(int) | 窗口 | 防连点 |
| 上传限流 | `rate:upload:{teacher_id}` | STRING(int) | 窗口 | 防刷接口 |
| QQ 绑定码 | `qq:bind:code:{code}` | STRING(JSON) | `BIND_CODE_TTL_SECONDS` | 存 student_id/class_id；一次性 |
| 绑定尝试计数 | `qq:bind:attempt:{openid}` | STRING(int) | 10 分钟 | 超 `BIND_MAX_ATTEMPTS` 直接拒绝 |
| 解析并发锁 | `lock:parse:{doc_id}` | STRING | 180s | 防同文档重复解析 |

**命名与实现规范：**

1. 所有 Key 必须由 `app/services/code_service.py` 或 `app/utils/cache_keys.py` 统一生成函数产出，禁止路由里手拼字符串。
2. Key 前缀常量集中在 `app/utils/cache_keys.py`，形如 `SESSION = "session:{jti}"`。
3. Redis 不可用时：鉴权直接 `50301`；限流降级为放行并打 WARN 日志（不允许因此放行敏感操作以外的写操作）。

### 7.3 逐接口定义

#### API-01 教师注册

- **鉴权**：匿名；限流 `RATE_LIMIT_LOGIN`（按 IP）。
- **请求**：

```json
{ "account": "teacher01@school.edu.cn", "name": "张老师", "password": "Abc12345", "email": "teacher01@school.edu.cn", "phone": "13800138000" }
```

- **校验**：`account` 4–64 字符，邮箱或 11 位手机号；`name` 1–50；`password` 8–32 且含字母与数字；`email`/`phone` 选填，填了则格式校验。
- **响应 200**：

```json
{ "token": "eyJhbGciOi...", "user": { "id": 1, "role": "teacher", "name": "张老师", "account": "teacher01@school.edu.cn" } }
```

- **失败**：40001 参数校验失败；40904 账号已存在；42901 限流。
- **边界**：账号大小写不敏感唯一（入库统一小写）；注册成功即签发会话，无需二次登录。

#### API-02 登录（教师 / 学生共用一个入口）

- **鉴权**：匿名；限流 `RATE_LIMIT_LOGIN`；失败计数写 `login:fail:{account}`（教师端 `{account}`=小写登录账号；学生端 `{account}`=`{class_code}:{student_no}`）。
- **教师请求**：

```json
{ "role": "teacher", "account": "teacher01@school.edu.cn", "password": "Abc12345" }
```

- **学生请求**（班级编号定位班级，不用邀请码，避免教师重置邀请码后学生无法登录）：

```json
{ "role": "student", "class_code": "C26001", "student_no": "20260101", "password": "Abc12345" }
```

- **响应 200**：

```json
{ "token": "eyJ...", "user": { "id": 10, "role": "student", "name": "李同学", "class_id": 1, "class_code": "C26001", "student_no": "20260101" } }
```

- **失败**：40001；40103 账号或密码错误（教师账号不存在与学生学号不存在统一用此码）；42901。
- **边界**：连续失败达 `RATE_LIMIT_LOGIN` 阈值后，窗口内直接 42901；密码比对固定使用 bcrypt，禁止先查库再比对造成时序差异。

#### API-03 登出

- **鉴权**：登录态。
- **请求**：空。
- **响应**：`data = null`。
- **失败**：40101 / 40102。
- **边界**：删除 `session:{jti}` 并写 `jwt:blacklist:{jti}`；重复登出不报错（幂等）。

#### API-04 当前用户

- **鉴权**：登录态。
- **响应（教师）**：`{ id, role: "teacher", name, account, created_at }`。
- **响应（学生）**：`{ id, role: "student", name, class_id, class_code, class_name, student_no, level, xp_total, qq_bound }`。
- **失败**：40101 / 40102。

#### API-05 创建班级

- **鉴权**：教师。
- **请求**：`{ "class_name": "2026级计算机1班", "course_name": "计算机网络" }`。
- **校验**：各 1–`TEXT_FIELD_MAX_LEN` 字符；教师最多持有 `MAX_CLASSES_PER_TEACHER` 个班级（超限 40907，文案提示归档旧班）。
- **响应 200**：

```json
{ "id": 1, "class_code": "C26A79", "class_name": "2026级计算机1班", "course_name": "计算机网络",
  "invite_code": "CLASS6", "invite_expires_at": null, "created_at": "2026-11-07 19:00:00" }
```

- **失败**：40301；40001；40907 班级数量已达上限；42901（创建限流同 LOGIN 窗口）。
- **边界**：`class_code` 与首个 `invite_code` 在同一事务内生成；碰撞重试 3 次后 50001。

#### API-07 班级详情

#### API-08 查询当前邀请码

- **鉴权**：教师本班。
- **响应**：`{ "invite_code": "CLASS6", "status": 1, "expires_at": null, "created_at": "..." }`。
- **失败**：40401；40302。
- **边界**：若历史码全部作废，返回 40401 并在 `message` 提示"请重置生成"。

#### API-09 重置邀请码

- **鉴权**：教师本班；限流 `RATE_LIMIT_INVITE_RESET`（按 class_id）。
- **请求**：空。
- **响应**：`{ "invite_code": "R9X2TB", "created_at": "..." }`。
- **失败**：40401；40302；42901。
- **边界（关键）**：事务内把该班全部 `status=1` 记录置 0，再插入新码；旧码立即失效（返回 40902）；已加入的学生不受影响；并发互斥用 **`class` 表行锁**（`SELECT ... FOR UPDATE` + 事务内 update），Redis 侧 `rate:invite:reset:{class_id}` 只做连点限流，不承担互斥。

- **失败**：40302；40401。
- **边界**：按 `student_no` 升序；`qq_bound` 由 `qq_binding(status=1)` 派生，不存冗余字段。

#### API-11 学生加入班级（核心接口）

- **鉴权**：匿名；限流 `RATE_LIMIT_JOIN`（按 IP）。
- **请求**：

```json
{ "invite_code": "K7M3QP", "student_no": "20260101", "name": "李同学", "password": "Abc12345" }
```

- **校验**：邀请码 6 位大写；学号 4–32 位字母数字；姓名 1–50；密码 8–32 含字母数字。
- **响应 200**：

```json
{ "token": "eyJ...",
  "user": { "id": 10, "role": "student", "name": "李同学", "class_id": 1, "class_code": "C26001", "student_no": "20260101" },
  "class": { "id": 1, "class_code": "C26A79", "class_name": "2026级计算机1班", "course_name": "计算机网络" } }
```

- **失败**：40001；40902 邀请码无效/过期/已作废；40901 该班学号已存在；42901。
- **边界**：
  1. 先校验邀请码（status=1 且未过 `expires_at`），再查 `(class_id, student_no)` 是否已存在。
  2. 邀请码错误与不存在统一返回 40902，不提示"码存在但班级停用"，防探测。
  3. 加入成功即签发会话，前端直接进入学生端。
  4. 学号大小写按原样保存，比对时不敏感。

#### API-12 批量上传文档（核心接口）

- **鉴权**：教师本班；限流 `RATE_LIMIT_UPLOAD`（按 teacher_id）。
- **请求**：`multipart/form-data`
  - `class_id`：文本字段，必填。
  - `course_name`：文本字段，选填（缺省取班级课程名）。
  - `files`：文件字段，可重复，`1 ≤ 数量 ≤ MAX_FILES_PER_REQUEST`。
- **处理规则**：逐文件独立事务；格式白名单 `UPLOAD_ALLOWED_EXT`；单文件 ≤ `UPLOAD_MAX_MB`；计算 sha256 去重（同班同 hash 直接判失败项 `40906` 并提示已存在）。
- **响应 200（部分成功也是 200）**：

```json
{ "total": 3,
  "success_list": [ { "file_name": "第3章.pdf", "doc_id": 5, "status": 2, "chunk_count": 42, "page_count": 12 } ],
  "fail_list": [ { "file_name": "扫描版讲义.pdf", "error_code": 42201, "error_message": "未检测到文本层，疑似扫描件，请上传可复制文字的 PDF" } ] }
```

- **失败**：40001（缺 class_id / 文件数为 0 / 超 `MAX_FILES_PER_REQUEST`）；40302；40401；42901。单文件的 41301 / 41501 进 `fail_list`，不整请求拒绝。
- **边界**：
  1. 单文件解析失败、格式不支持（41501）、超过 `UPLOAD_MAX_MB`（41301）**均不阻塞**其余文件，只进 `fail_list`；`fail_list.error_code` 与统一响应 `code` 同为 **int**。
  2. 文件落盘命名 `{class_id}/{sha256[:2]}/{sha256}{ext}`，原始文件名只存数据库（防目录穿越）。
  3. 解析超时（`PARSER_TIMEOUT_SECONDS`）记为 `42202`，文档状态置 3，可删除重传。
  4. 全部文件都失败时仍返回 200 + 空 `success_list`，由前端展示失败清单。
  5. 只有请求级错误（缺 class_id、文件数为 0、超 `MAX_FILES_PER_REQUEST`、总字节超 `MAX_TOTAL_UPLOAD_MB`）才整请求失败（40001）；单文件问题一律进 `fail_list`。

{ "total": 42, "page": 1, "page_size": 10,

- **失败**：40401；40302。

- **失败**：40401；40302。

#### API-17 生成 QQ 绑定码

- **鉴权**：学生本人。
- **请求**：空。
- **响应**：

```json
{ "code": "48392017", "expires_in": 600, "expires_at": "2026-11-07 19:10:00" }
```

- **失败**：40301（教师调用）；40101/40102。
- **边界**：同一学生重复生成时覆盖旧码（先 `DEL` 旧 key）；8 位数字，首位非 0；写 `qq:bind:code:{code}`，TTL 600 秒。

#### API-18 QQ 绑定回调（机器人调用）

- **鉴权**：请求头 `X-Bot-Secret` 必须等于 `BOT_SHARED_SECRET`，否则 40101。
- **请求**：

```json
{ "code": "48392017", "qq_openid": "A1B2C3D4E5F6..." }
```

- **响应 200**：

```json
{ "student_id": 10, "student_no": "20260101", "class_id": 1, "class_code": "C26001", "bound_at": "2026-11-07 19:03:00" }
```

- **失败**：40001；40905 绑定码无效或已过期；40903 该 QQ 已绑定其他学号；42901（尝试超限）。
- **边界（关键）**：
  1. 校验顺序：`X-Bot-Secret` → 尝试计数 `qq:bind:attempt:{openid}` ≤ `BIND_MAX_ATTEMPTS` → 取码 → 校验码 → 查冲突。
  2. 绑定成功必须 **原子消费**：`GETDEL qq:bind:code:{code}` 或 Lua 脚本，保证同一码只能用一次。
  3. 改绑：先把该学生 `status=1` 的行置 0（生成列 `active_student_id` / `active_qq_openid` 自动变 NULL，不再占唯一位），再插入新行；唯一约束只作用于 `status=1` 的行。
  4. 同一 QQ 已有其他学号绑定 → 40903，不允许顶替。
  5. 该接口幂等：同码重复调用第二次返回 40905。

#### API-19 解绑 QQ

- **鉴权**：学生本人。
- **响应**：`data = null`。
- **失败**：40401（无绑定）；40101/40102。
- **边界**：`status` 置 0 保留历史，不物理删除；解绑后学生可重新绑定。

#### API-20 健康检查

- **鉴权**：匿名。
- **响应**：

```json
{ "status": "ok", "version": "0.1.0",
  "checks": { "mysql": "ok", "redis": "ok", "qdrant": "skipped" }, "timestamp": "2026-11-07 19:05:00" }
```

- **状态码**：全依赖正常 200；任一必需依赖异常 503 + `50301`；Qdrant 在 `VECTOR_INDEX_ENABLED=false` 时返回 `skipped` 且不影响 200。

### 8.1 解析器策略（Parser）

```python
# app/strategies/parser/base.py
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import List, Optional

@dataclass
class ParsedChunk:
    content: str                 # 必填，去首尾空白后非空
    chapter_title: Optional[str] = None
    page_no: Optional[int] = None

@dataclass
class ParseResult:
    title: Optional[str] = None          # 文档主标题，取不到用文件名
    page_count: Optional[int] = None     # 无页概念为 None
    chunks: List[ParsedChunk] = field(default_factory=list)

class ParserError(Exception):
    code: str = "42202"

class UnsupportedFormat(ParserError): code = "41501"
class NoTextLayer(ParserError): code = "42201"       # 扫描件/图片型

class BaseParser(ABC):
    """所有解析器必须实现；构造函数只接收配置，不读全局变量。"""

    supported_ext: tuple[str, ...] = ()

    def __init__(self, *, min_text_chars: int, chunk_size: int, chunk_overlap: int,
                 timeout_seconds: int):
        self.min_text_chars = min_text_chars
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap
        self.timeout_seconds = timeout_seconds

    @abstractmethod
    def extract(self, file_path: str) -> ParseResult:
        """抽取结构化文本；失败抛 ParserError 子类，禁止返回空壳结果。"""

    def split(self, text: str, *, base_chapter: str | None = None,
              page_map: dict[int, int] | None = None) -> list[ParsedChunk]:
        """按 chunk_size/overlap 切分；page_map 用于把字符偏移映射到页码。"""
```

**注册表（新增格式只加实现类，不改调用方）：**

```python
# app/strategies/parser/registry.py
_PARSERS: dict[str, type[BaseParser]] = {}

def register(ext: str):
    def deco(cls):
        _PARSERS[ext.lower()] = cls
        return cls
    return deco

def get_parser(ext: str, settings) -> BaseParser:
    cls = _PARSERS.get(ext.lower())
    if not cls:
        raise UnsupportedFormat(f"不支持的文件类型: {ext}")
    return cls(min_text_chars=settings.PDF_MIN_TEXT_CHARS,
               chunk_size=settings.CHUNK_SIZE,
               chunk_overlap=settings.CHUNK_OVERLAP,
               timeout_seconds=settings.PARSER_TIMEOUT_SECONDS)

# 各实现类顶部：@register("pdf") / @register("docx") / @register("pptx") / @register("md") / @register("txt")
```

**实现要求：**

| 实现 | 关键点 | 扫描件判定 | 页码 |
|---|---|---|---|
| PdfParser | 优先 `pdfplumber` 抽文本；抽不到再试 `pypdf` | 全文可打印字符 < `PDF_MIN_TEXT_CHARS` → `NoTextLayer` | 有（逐页映射） |
| DocxParser | `python-docx`，按段落 + 标题样式分级 | 不适用 | 无（NULL） |
| PptxParser | `python-pptx`，**只取文本框文字，不做 OCR**；按幻灯片分章 | 不适用 | 幻灯片序号记为 `page_no` |
| MarkdownParser | 按 `#` 层级分章；保留正文 | 不适用 | 无 |
| TxtParser | 按空行分段；编码探测（utf-8 → gb18030，严格解码失败即换） | 不适用 | 无 |

> 阈值归属已裁决：`PDF_MIN_TEXT_CHARS`、`CHUNK_SIZE`、`CHUNK_OVERLAP`、`PARSER_TIMEOUT_SECONDS` 全部来自环境变量（见 4.6），**不建配置表**。

### 8.2 存储策略（Storage）

```python
# app/strategies/storage/base.py
from abc import ABC, abstractmethod

class BaseStorage(ABC):
    @abstractmethod
    def save(self, *, content: bytes, class_id: int, file_hash: str, ext: str) -> str:
        """返回相对路径（相对 UPLOAD_DIR），禁止返回绝对路径。"""

    @abstractmethod
    def read(self, relative_path: str) -> bytes: ...

    @abstractmethod
    def delete(self, relative_path: str) -> None:
        """文件不存在视为成功（幂等）。"""

    @abstractmethod
    def exists(self, relative_path: str) -> bool: ...

# app/strategies/storage/local_storage.py
class LocalStorage(BaseStorage):
    def __init__(self, root: str):
        self.root = os.path.realpath(root)          # 启动时校验目录可写

    def _abs(self, relative_path: str) -> str:
        p = os.path.realpath(os.path.join(self.root, relative_path))
        if not p.startswith(self.root + os.sep):
            raise ValueError("路径越界")             # 防目录穿越
        return p
```

### 8.3 切片落库与向量占位（服务层伪代码）

```python
def ingest_document(db, storage, *, class_id, teacher_id, file, course_name) -> DocResult:
    ext = file.filename.rsplit(".", 1)[-1].lower()
    if ext not in settings.ALLOWED_EXT_SET:
        raise UnsupportedFormat          # 41501
    content = file.read()
    if len(content) > settings.UPLOAD_MAX_BYTES:
        raise FileTooLarge               # 41301
    digest = sha256(content)
    if doc_repo.exists_hash(class_id, digest):
        raise DuplicateDoc               # 40906

    rel_path = storage.save(content=content, class_id=class_id, file_hash=digest, ext=ext)
    doc = doc_repo.create(class_id=class_id, ..., status=1)
    try:
        parser = get_parser(ext, settings)
        result = parser.extract(storage._abs(rel_path))
        chunks = result.chunks
        if not chunks:
            raise NoTextLayer            # 42201
        with db.transaction():
            for idx, ch in enumerate(chunks):
                chunk_repo.create(doc_id=doc.id, class_id=class_id, chunk_index=idx,
                                  doc_name=doc.title, content=ch.content, char_count=len(ch.content),
                                  chapter_title=ch.chapter_title, page_no=ch.page_no)
            doc.status = 2
            doc.page_count = result.page_count
            doc.chunk_count = len(chunks)
        if settings.VECTOR_INDEX_ENABLED:      # M1 默认 false
            vector_repo.upsert_chunks(class_id, doc.id, chunks)   # 🔜 M3
        return DocResult(doc_id=doc.id, status=2, chunk_count=len(chunks))
    except ParserError as e:
        doc.status, doc.error_code, doc.error_message = 3, e.code, str(e)
        raise
```
