## 三、执行中的口径说明（不算失败）

1. **限流触发后分段续跑**：注册/登录共用 `RATE_LIMIT_LOGIN=5/300`，一轮脚本超过 5 次会被 429。已清空**验收自身产生**的 `rate:login` / `rate:join` 计数后分段执行；限流本身不在 AC 范围，未改任何阈值配置。
2. **join 限流 10/3600**：脚本用独立班级与独立学号，未复用被限流窗口的凭证。
3. **AC-01 未重复起 prod**：dev api 占用 8000，prod 同端口冲突；沿用当日 I1 的 prod 五服务实测日志（`prod-up.log`、`prod-ps.log`、`prod-web-health.log`、`upload-110m.log`），非“声称跑过”。
4. **AC-19/35 的视觉证据**用 I2 的 8 张 1440 截图，未跨浏览器矩阵（TD-07）。
5. **API-18 回调**按密钥边界用 `X-Bot-Secret` 直连验证，不经浏览器；符合契约。
