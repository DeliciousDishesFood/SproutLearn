## 五、风险

1. **40303 路由拦截依赖 `/auth/me`**：网络失败时守卫不清会话，业务接口仍会返回 40303 并由全局事件兜底；两条路径都已验证。
2. **40001 优先后端文案**：若后端返回技术性字段信息，用户会直接看到；当前密码场景已由后端给出中文文案。
3. **临时密码交付**：只存在页面内存，复制后进入剪贴板；无法控制剪贴板历史，需教师当面交付并立即让学生改密。
4. **归档恢复**：归档会递增学生 `auth_version`，恢复后旧会话不会复活，学生需重新登录（后端既定行为）。
5. **教师账号入口**：新增 `/teacher/settings` 与侧栏“账号”，与班级设置“设置”分开；导航 active 判断已按路径区分。
6. **夹具非真实后端**：浏览器验证使用本地假响应夹具，真实会话撤销、DB 版本号与 MySQL 行为以 `docs/v1.4-账号与班级基础管理-P13.md` 的后端测试为准。
