# 派工：新前端 v1.4 账号与班级基础管理（Trae 前端窗口）

> 可直接复制给 Trae。先读 `docs/决策-v1.4-账号与班级基础管理.md` 和后端最终契约。只改 `frontend-v3/` 与契约镜像，不改 backend/旧 frontend/，不新增 UI 依赖，不提交。

## 一、目标

在现有青柠＋石墨视觉与组件体系内补账号安全、临时密码强制改密、学生停用/恢复、班级归档/恢复。不要做邮箱找回、设备管理、审计中心、密码强度条或管理员后台。

## 二、F0 契约与密码规则

1. 等后端契约落地后同步 `src/api/contract.ts` 与 docs 镜像，SHA256 一致；不得臆造字段。
2. 新增 `api/account.ts` 或扩展 `api/auth.ts`：自助改密、重置学生密码、学生状态、班级归档/恢复。
3. 教师注册、学生入班、学生/教师改密统一文案：**“8–32 位，且同时包含字母和数字”**；删除“至少 6 位”。前端提示与后端校验一致，但不以前端校验代替后端。
4. 新错误码映射：40303 必须改密、40304 账号停用、40305 班级归档；40001 优先展示后端具体密码错误。

## 三、F1 学生/教师自助改密

- 学生：`ProfileView` 增加“账号安全”区，保留 QQ 绑定，不堆大段说明。
- 教师：`SettingsView` 增加“账号安全”区。
- 共用 `ChangePasswordForm`：当前/临时密码、新密码、确认新密码；显示/隐藏密码按钮有中文 aria-label。
- 新密码与确认一致、不得与当前密码相同；提交 loading 防重复；错误保留输入，成功后才清表单。
- 成功文案：“密码已更新，请使用新密码重新登录”。随后调用本地清会话并跳 `/login`，不把旧 token 留在 localStorage。

## 四、F2 临时密码强制改密

1. 登录或 `/auth/me` 返回 `must_change_password=true` 时，路由只能进入 `/account/change-password?forced=1`。
2. 强制页使用简洁独立布局，不显示可绕过改密的业务导航；说明“临时密码只能用于本次登录，设置新密码后才能继续”。
3. 后端 40303 时统一跳强制页；40102 才清会话；40304 显示账号已停用；40305 显示班级已归档。
4. 改密成功清会话并回登录页；不能用前端 flag 自行解除，必须以后端 `/auth/me` 为准。

## 五、F3 教师重置学生密码

入口：`ClassDetailView → 学生 → 行操作 → 重置密码`。

1. 使用现有 `ConfirmDialog`，展示学生姓名、学号和后果：所有设备退出、临时密码首次登录必须改密、历史数据与 QQ 绑定保留。
2. 成功后打开一次性临时密码弹窗：
   - 临时密码大号等宽、复制按钮、复制成功反馈；
   - 明示“只显示这一次，关闭后无法再次查看”；
   - 关闭二次确认或明确“我已保存”；
   - 不把临时密码写入 Pinia/localStorage/URL/截图文件名/console。
3. 请求失败保留学生上下文，可重试；42901 显示稍后重试；40302 不泄露跨班信息。
4. 临时密码属于演示敏感信息，正式验收截图必须打码或用假响应夹具。

## 六、F4 学生停用/恢复

- 同一学生行提供“停用/恢复”，复用 ConfirmDialog；停用为 danger，恢复为 primary。
- 列表用现有状态 badge 显示“正常/停用”，可加“全部/正常/停用”即选即生效筛选，不加多余查询按钮。
- 停用说明：退出所有设备、停止作答/通知/QQ 服务，历史成绩/XP/绑定保留。
- 成功后更新当前行，不整页闪白；失败回滚乐观状态并 toast。

## 七、F5 班级归档/恢复

- `ClassListView` 增加“活跃/已归档”筛选；默认活跃。
- `ClassCard` 或班级设置提供归档；归档 ConfirmDialog 说明：停止新增/发布/通知/QQ，历史数据保留，可恢复。
- 归档班使用低强调 badge，不物理删除；恢复用 primary。
- 活跃班达到上限时，错误动作链接到“已归档”视图或归档入口；不能只提示“请归档”却没有入口。
- 归档班详情按后端 40305 显示只读状态，不把所有按钮简单隐藏后又让直接 URL 可写。

## 八、文档与视觉边界

- 文档中心直接使用后端角色过滤结果，不另写 slug 黑名单。
- 复用 BaseModal、ConfirmDialog、BaseTabs、BaseField、EmptyState；焦点圈定/恢复、Escape、44px 触控、375 无横溢。
- 不改登录页石墨画布、答题页布局，不借本版本继续美化其他页面。
