# QQ 机器人录制脚本（6–8 分钟主线）

> 演示账号：教师 `demo.teacher@school.edu.cn / Demo@123`；班级 `C26A79`；学生 `20260101–20260110 / Demo@123`。
> 数据：独立 `sproutlearn_demo` / `demo.db`，见 `QQ机器人演示数据说明.md`。真实 Secret/token 不读、不拍、不说。

## 0. 录制前检查（1 分钟，不录）

- 系统时间、网络、QQ 群机器人权限；群内 @机器人 有响应。
- `verify_qq_demo --sqlite <demo.db>` 输出 `RESULT: PASS`。
- `qq_demo_preflight` 离线项：DB/Redis/demo class/bot_config/LLM provider 均 true。
- worker 已启动且日志出现 `qq gateway READY`；浏览器 localStorage 清空，devtools 关闭。
- 准备备用：一份已跑通的离线 smoke 输出、一张群通知失败 `BotNotice=failed` 的截图。

## 1. 启动服务（不录或快剪）

```powershell
cd E:\ai-dev-projects\SproutLearn\backend
& "C:\Users\OMEN\venvs\sproutlearn-backend\Scripts\python.exe" -m uvicorn app.main:app --host 127.0.0.1 --port 8000
# 另开窗口
& "C:\Users\OMEN\venvs\sproutlearn-backend\Scripts\python.exe" -m app.qq_bot_worker
```

预期：worker 日志 `qq gateway READY`。没有 READY 不进入正式录制。

## 2. 主线逐句（6–8 分钟）

### 2.1 教师登录与群绑定（约 60 秒）

1. 浏览器登录教师；进入「班级设置 → QQ 机器人」。
2. 页面显示 `app_id=env` 占位、密钥由环境变量托管；点击“测试连接”显示成功（不展示 token）。
3. 点击“生成群绑定码”，得到 8 位码（10 分钟有效）。
4. 在 QQ 群 @机器人：`绑定群 <码>`。
5. 预期：`本群已绑定班级 计算机网络演示班，教师身份已绑定`。
6. 若提示已被其他老师绑定：现场执行 `解绑教师` 后重新生成码。

### 2.2 学生绑定（约 40 秒）

1. 学生网页登录 `20260101 / Demo@123`，个人中心生成 8 位绑定码。
2. QQ 私聊机器人：`绑定 <码>`。
3. 预期：`已绑定 20260101/计算机网络演示班`。

### 2.3 学生查询（约 40 秒）

1. QQ 发：`作业` → 预期列出《计算机网络基础·第一次作业》和截止时间。
2. 发：`成绩` → 预期显示随堂练习/已判分记录（只显示本人）。
3. 若老师关闭查询：预期 `老师未开放作业查询/成绩查询`，不显示他人数据。

### 2.4 教师查询与催交（约 90 秒）

1. 教师在群 @机器人：`作业`。
2. 预期概览：《计算机网络基础·第一次作业》、开始/截止、`已交：4/10`、未交前 10。
3. 发：`作业情况` → 完整 6 人未交名单。
4. 发：`催交` → 尝试 @未交学生；成功时显示 @，失败时纯名单并追加 `@ 失败，已发名单`。
5. 发：`作业通知` → 群里立即收到被动 `【新作业】...`（当前权限下最稳的补发方式）。

### 2.5 发布作业与站内通知（约 60 秒）

1. 教师网页发布一份新作业（或复用演示数据中的新作业）。
2. 若主动群消息成功：群内收到 `【新作业】...`；若失败（如 40034105）：页面提示“群主动消息权限不足”，站内通知仍成功，`bot_notice.status=failed`。
3. 不要重复点击发布造成刷屏；重复发布不会重复 assignment 通知。

### 2.6 AI 问答（约 90 秒）

1. 学生在群 @机器人：`TCP 和 UDP 有什么区别？`
2. 预期：基于 demo 知识切片回答，纯文本、无 Markdown/LaTeX、先给思路。
3. 追问：`什么是三次握手？` → 预期引用了三次握手切片；若 10 秒内连续问，提示稍后再问。
4. 若 LLM 不可用：预期 `我暂时没查到，换个问法或发送 帮助`，不要展示异常栈。

### 2.7 收尾（约 30 秒）

- 教师 `帮助`/学生 `帮助` 显示各自命令。
- 关闭查询权限演示一次拒绝；再打开恢复。
- 结束：停止 worker（仅录制结束，不提交/不 push）。

## 3. 失败备用路径

| 失败 | 现场处理 |
|---|---|
| 群未绑定/教师身份未确认 | 重新生成群绑定码，@机器人 `绑定群`；已有其他老师先 `解绑教师`。 |
| 主动消息 40034105 | 不谎称群发成功；展示站内通知 + 让老师在群里发 `作业通知` 被动补发。 |
| @ 不支持 | 展示纯名单和 `@ 失败，已发名单`；不声称已 @。 |
| LLM 超时/不可用 | 展示友好提示；切回网页知识/模板/离线 smoke 证据。 |
| gateway 断开 | 展示 worker 重连日志；若未 READY，改用离线 smoke + 截图，不伪造在线。 |
| Redis 不可用 | 说明限流降级放行；不声称限流仍生效。 |
| 群通知发送失败 | 展示 `bot_notice.status=failed`，站内通知仍成功。 |

## 4. 录制禁止

- 不读/不拍 `QQ_BOT_APP_SECRET`、token、数据库密码。
- 不展示完整 openid；如需展示只显示末 4 位。
- 不用 mock 回复冒充真实 QQ 群消息；离线 smoke 单独说明。
- 不重复发布作业造成刷屏。
- 不把默认 `docker compose config` 输出贴入录屏/日志。
