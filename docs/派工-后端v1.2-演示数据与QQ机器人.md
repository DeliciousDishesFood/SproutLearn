## 一、你的角色与已知现状

你是青芽 SproutLearn 后端工程师。项目：`E:\ai-dev-projects\SproutLearn`；后端：`backend`；前端只读：`frontend-v3`；旧前端只读：`frontend`。

**不要重造 QQ 功能。当前已有：**
- `app/services/qq_bot/worker.py`：网关事件循环＋60 秒到期提醒。

### D4 真实 QQ + 真实 LLM 录制彩排（P0，必须和离线分开）

只有用户环境已有真实凭据时执行；没有就明确阻塞，不 mock 成“在线成功”。按 `docs/demo/QQ机器人录制脚本.md` 走两遍：

2. QQ 群：`@小芽 绑定群 <8位>` → 回复“本群已绑定班级…”。
3. 学生网页生成绑定码 → QQ 私聊/群内 `绑定 <8位>` → 回复学号/班级。
4. 学生：`作业`、`成绩`；教师：`作业`、`作业情况`、`催交`。
5. 前端发布一份新作业 → 群内 `【新作业】`；重复发布不重复通知。
6. 学生：`@小芽 TCP 和 UDP 有什么区别？` → 基于 demo 知识库回答；追问 `三次握手呢？`；检查回答纯文本、长度和耗时。
7. 学生提交一次作业 → 教师再查 `作业`，统计变化；站内通知不丢。
8. 记录：token/READY、命令、真实回复截图、耗时、BotNotice 状态。截图不得含 secret/token。

### D5 失败兜底与备用录制（P0/P1）

必须有可演示的兜底，不临场靠运气：
