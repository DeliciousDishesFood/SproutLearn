## 二、谁做了什么 / 改动文件

### F0 既有阻断项
- `router/index.ts`：`sessionVerified` 每次页面生命周期强制校验一次 `/auth/me`；仅 `40101/40102` 清会话并跳登录；网络/5xx 保留会话交给页面。
- `stores/auth.ts`、`api/auth.ts`：新增 `sessionVerified`；`logout` 无 token 不发请求且 `skipAuthRedirect`。
- `main.ts`：会话失效清 `sprout.v3.currentClassId`。
- `AppShell.vue`：旧 `currentClassId` 按 `/classes` 回落，避免跨后端旧 ID。
- `LoginView/RegisterTeacherView/JoinClassView`：删除本地金句兜底与静态故事金句；接口失败隐藏。
- `QuestionsView`：`openImport()` 默认 `ai`，模板第二 tab；`.xls` 自动切 `ai-preview`；原生 input 保持隐藏。
- `BanksView/ClassListView/ClassDetailView/PapersView/QuestionsView`：空态去掉与页头重复的动作与解释段。
- 全站删除静态营销 `page-head__lede`（13 处），保留校验/错误/危险确认/计数/截止/QQ 必需说明。

### F1 对比度、焦点、字号
- `tokens.css`：新增 `--text-3:#687180`（白底 4.93:1、浅面 4.63:1），暗色 `#98A2AE`；`--tertiary` 仅用于禁用/占位；新增 `--focus-ring`、`--z-*`。
- `base.css`：全局焦点改 `2px solid var(--lime-text)` + `outline-offset:2px`；checkbox/switch/heat 补实色轮廓；正文 13.5、表头 12、辅助 12、最小 11；标题去负字距并 `text-wrap:balance`。
- `scripts/contrast-check.mjs`：零依赖解析 token，校验明暗两套文字/焦点对比度。

### F2 焦点闭环
- 新增 `composables/useFocusTrap.ts`：焦点栈（嵌套只响应最上层）、Tab 循环、Escape、记录触发元素、body overflow 还原、卸载清理、`isConnected` 防恢复已卸载节点。
- `BaseModal.vue`：`aria-labelledby/aria-describedby`、`role=dialog`、首焦点、Escape/遮罩规则。
- `AppShell.vue` 移动抽屉、`AskSproutPanel.vue` 小芽抽屉复用同一陷阱。

### F3 键盘语义与滑动
- `BaseSelect.vue`：option 稳定 id、`aria-activedescendant`、Home/End 跳过 disabled、Escape 回触发器；下拉 z-index 高于弹窗。
- `BaseTabs.vue`：roving tabindex、左右/Home/End、`aria-controls`；`ClassDetailView`/`QuestionsView` 面板配对 `tabpanel/aria-labelledby`。
- 新增 `AttemptQuestionBody.vue`：原生 radio/checkbox + fieldset/legend，视觉隐藏但可聚焦（非 `display:none`）。
- `AttemptView.vue`：手机 scroll-snap 单题滑块，`scroll` debounce 同步题号与答题卡，`goTo` 平滑滚动带抑制窗口，避免递归。

### F4 确认与真实失败出口

浏览器走查（1440/1024/375/390，Edge + 本地接口夹具）关键断言：

- 会话：首次受保护导航 `/auth/me` 调用 1 次。
- 导入：默认 `AI 智能识别`；`aria-controls=import-tab-panel`、面板 `role=tabpanel`；打开后焦点在弹窗内、Tab 环绕、Escape 关闭且焦点回“导入题目”。
- BaseSelect：`aria-activedescendant` 随 Arrow 移动、Home 跳过 disabled、Escape 关合并回触发器。
- 作答：原生 `radio` + `checkbox` 均存在且可聚焦；保存 500 → 出现重试 → 重试成功回“已保存”；提交弹窗 primary。
- 讲评 503 → 保留题目/答案 + “重新生成”成功；未创建新 attempt。
- QQ：四步；未保存徽标 + 测试禁用；503 → 连接失败；恢复 → 连接正常；群未绑定/已绑定；绑定码倒计时跳动。
- 确认：产品内 `role=dialog`、danger 按钮、对象名可见、取消关闭；无原生 dialog 事件。
- 移动 375：统计 1 列、主要按钮 44px、答题滑动同步到 2/5、题目表隐藏次级列且有横滚提示、页面无横溢。
- 1024 统计 2 列无横溢；390 学生首页无横溢；125% 缩放无横溢；暗色无横溢；reduced-motion 骨架 `animation:none`、打字机直显。
- 源码：`window.confirm`=0、`<select`=0、硬编码金句=0；契约镜像 SHA256 两侧一致 `A7087A54…8BB754`。

3 条 console error 均为验收脚本主动注入的 500/503，用于验证真实失败出口。

## 五、风险

- 热力图 52 周在 1024/375 需图内横滚；已加 aria 读数与键盘，但桌面缩放后命中面积略低于 24px（见 P2-4）。
- QQ“学生绑定”只展示“由学生发起”，教师端不展示明细，也不显示 worker 状态；群/学生真实绑定仍需按后端录屏证明。
- 答题手机滑块与桌面是两套 DOM（共用 `AttemptQuestionBody`），后续改题卡样式需同步检查 `q-slide` 容器。
- `useFocusTrap` 采用冒泡阶段监听并尊重 `defaultPrevented`，若有第三方控件在捕获阶段处理 Escape 可能绕过；本项目无此情况。
- 后端/旧前端/其他窗口改动未纳入本轮，未提交，工作树存在多窗口并行变更。
