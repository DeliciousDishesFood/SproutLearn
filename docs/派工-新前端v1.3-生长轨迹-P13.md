## 6. 风险与后续

1. **`.btn` 移动端 44px、`--lime-text` 深色调整属于全局影响**：已在试卷列表抽验，但教师端表格密集页未逐页截图，下一轮建议补 2–3 个教师页的移动端抽验。
2. **答题页旧样式残留**：`base.css` 中 `.practice / .q-card / .side-card / .sheet*` 等旧作答样式已不被本页引用，为避免与并行窗口冲突本轮不删除；后续可统一清理。
3. **短题下方留白**：1440×900 下题干与选项结束后仍有约 200px 空白。这是 `height:100dvh`＋底部固定操作栏的结构结果，本轮按要求未加入任何虚构解析或额外卡片；若需收紧，需要产品层面决定是否让底栏随内容浮动。
4. **答题卡只标当前题的保存态**：正式保存状态机是全局的 `saveState`，因此答题卡只能对「当前题」显示保存中/失败，其余题不标；未为此重写状态机。
5. **小芽素材自带天蓝圆底**：与原图一致，按要求不重绘、不去背，用 56px 圆徽章＋青柠细环收纳。
6. **开发库残留**：本轮创建了 3 张验收用练习卷，其中 129/130 因首次 PowerShell 提交编码问题标题为乱码，后端不提供已发布试卷的删除/撤回接口，故残留在教师与学生列表中；131「网络安全基础 · 单元练习」为正式验收卷。
7. **未覆盖页面**：学生 Home / Result / Growth / Profile / Docs、教师端全部页面、AppShell 导航未做改造；下一轮若扩展到 Home/Result，可直接复用 `--graphite*`、`--stage-cool`、`OptionRow` 样式与 `SaveStateIndicator`，但不建议把 Result 也改成深色阅读面——答题与结果是「阅读面」，深色应继续只属于品牌画布。
