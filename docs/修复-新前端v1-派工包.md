### T3｜学生作答自动保存与提交竞态（P0）

文件：`src/views/student/AttemptView.vue`

现状：

- `pendingSaves` 只在内存 Set；`persist` 发请求前就 `delete`。
- `flushSaves` 只取当前 pending，不等在途请求。
- `persist` catch 只 toast，不抛错、不重排队。
- `submit` 在 `flushSaves()` 后无条件提交。

目标语义：

- `pendingSaves` = 有未确认落库的题目；**保存成功且版本未变才删除**。
- `inflight` = 每题目在途 Promise；`versions` = 每次 `setAnswer` 递增的版本号。
- 提交前先等在途，再重试所有 dirty；任一失败则**不提交**。
- 退出时保存失败要二次确认，不能静默丢。

参考实现：

```ts
const pendingSaves = new Set<number>()
const inflight = new Map<number, Promise<void>>()
const versions = new Map<number, number>()

function setAnswer(questionId: number, value: unknown): void {
  answers[String(questionId)] = value
  versions.set(questionId, (versions.get(questionId) ?? 0) + 1)
  pendingSaves.add(questionId)
  const existing = timers.get(questionId)
  if (existing) window.clearTimeout(existing)
  timers.set(
    questionId,
    window.setTimeout(() => {
      timers.delete(questionId)
      void persist(questionId).catch(() => undefined)
    }, 500),
  )
}

async function persist(questionId: number): Promise<void> {
  const existing = inflight.get(questionId)
  if (existing) return existing
  if (!pendingSaves.has(questionId)) return

  const task = (async () => {
    try {
      while (pendingSaves.has(questionId)) {
        const version = versions.get(questionId) ?? 0
        const value = answerValue(questionId)
        saveState.value = 'saving'
        await attemptsApi.saveAnswer(attemptId.value, questionId, value ?? null)
        if ((versions.get(questionId) ?? 0) === version) {
          pendingSaves.delete(questionId)
        }
      }
      saveState.value = pendingSaves.size === 0 ? 'saved' : 'saving'
    } catch (error) {
      saveState.value = 'error'
      toast.error(`保存失败：${toUserMessage(error)}`)
      throw error
    }
  })()

  inflight.set(questionId, task)
  try {
    await task
  } finally {
    if (inflight.get(questionId) === task) inflight.delete(questionId)
  }
}

async function flushSaves(): Promise<void> {
  timers.forEach((timer) => window.clearTimeout(timer))
  timers.clear()

  // 先等在途；失败的保留在 pending，下面统一重试
  await Promise.allSettled([...inflight.values()])
  await Promise.all([...pendingSaves].map((id) => persist(id)))

  if (pendingSaves.size > 0) {
    throw new Error('仍有答案未保存')
  }
}
```

`submit`：

```ts
try {
  await flushSaves()
  const result = await attemptsApi.submit(attemptId.value)
  ...
} catch (error) {
  if (isApiError(error) && error.code === 40910) { ... }
  else if (!isApiError(error) || error.code !== 40910) {
    toast.error('答案保存未完成，未提交；请检查网络后重试')
  }
}
```

- 不要吞掉 `flushSaves` 的失败；不要先 `submit` 再补保存。
- `exit`：

```ts
try {
  await flushSaves()
} catch {
  if (!window.confirm('仍有答案未保存成功，仍要退出吗？')) return
}
await router.push('/student/papers')
```

- 可选：`beforeunload` 在 `pendingSaves.size || inflight.size` 时提示；不要阻塞正常提交。

验收：

- 代码层：不存在“请求前 delete pending”；`flushSaves` 先等 `inflight`；`catch` 抛出；`submit` 失败不提交。
- 浏览器：选答案后立刻点提交（不等 500ms），结果页能看到最后答案；用网络节流制造慢请求，提交仍等待保存完成。
- 保存失败注入（断网/500）时，提交被阻止并提示；恢复网络后重试可提交。
- 退出时保存失败弹二次确认；取消后仍在答题页。

### T5｜API 客户端 baseURL 与 200 信封错误（P1/P2）

文件：`src/utils/constants.ts`、`src/api/client.ts`、`src/api/questions.ts`（SSE 引用确认）。

1. 统一派生：

```ts
function normalizeApiBase(raw: string | undefined): string {
  let root = (raw || '/api').trim().replace(/\/+$/, '')
  if (!root) root = '/api'
  if (/\/v1$/.test(root)) return root
  if (/\/api$/.test(root)) return `${root}/v1`
  return `${root}/api/v1`
}

export const API_BASE_URL = normalizeApiBase(env.VITE_API_BASE_URL)
```

接受：`/api`、`/api/v1`、`http://127.0.0.1:8000`、`http://127.0.0.1:8000/api`、`http://127.0.0.1:8000/api/v1`。

3. 提取错误处理：

```ts
function handleApiError(apiError: ApiError, config?: AxiosRequestConfig): void {
  const skipGlobalError = config?.skipGlobalError === true
  const skipAuthRedirect = config?.skipAuthRedirect === true
  if (isSessionCode(apiError.code) && !skipAuthRedirect) {
    clearSession()
    notifySessionExpired(apiError.friendlyMessage)
  } else if (!skipGlobalError) {
    notifyToast(apiError.friendlyMessage, 'error')
  }
}
```

4. fulfilled 分支 `body.code !== 0` 时构造 `ApiError`，调用 `handleApiError(apiError, response.config)`，再 `return Promise.reject(apiError)`；rejected 分支也调用同一个 `handleApiError`。
