# 派工-新前端 v1.5 演示视觉与「问问小芽」— P13 汇报

## 一、背景与目标

终点演示前的最后一轮 UI 精修，基线为 v1.4 未提交工作树。目标是让「问问小芽」、结果页与 AI 讲评弹层、手机学生表达到与 Growth Track 一致的完成度，并在学生首页、成长页、教师工作台、账号设置页补适度品牌焦点。本轮没有重做信息架构，没有推翻 Growth Track，没有修改后端业务。

实际样式目录为 `src/design/tokens.css` 与 `src/design/base.css`，任务中提到的 `src/styles/theme.css` 在本工程不存在；学生「设置页」实际对应 `src/views/student/ProfileView.vue`，本轮在该文件内调整。

## 三、页面级视觉/交互改动清单

### 1. 问问小芽

- 桌面恢复为右侧悬浮抽屉：宽 392px、22px 圆角、细边线、轻阴影，距视口四边 16px，`dvh` 高度；移动端为底部抽屉，顶部 24px 圆角，`max-height: 88dvh`，输入区计入 `env(safe-area-inset-bottom)`。
- 头部使用项目内 `xiaoya-bot.png`（40px 底座、青柠状态点），标题「问问小芽」+「围绕当前题目追问」；关闭按钮 44×44、`aria-label="关闭问问小芽"`。
- 空态改为头像 + 一句说明 + 3 个快捷 chip（只填入输入框，不自动发送）+ 低权重边界说明。
- 用户气泡为石墨底浅色字、18px 圆角；小芽气泡为冷灰阅读面；最大宽度 88%，长文自然换行。
- 来源仅在接口返回 `sources` 时显示为「来源 + 文档小标签」；无来源不显示任何出处。
- 思考态为文字 + 静态浅骨架，无持续动画。
- 失败时保留用户消息并内联展示错误与重试；重试复用原消息与原文 selected_text，不重复插入用户气泡。429 继续倒计时，503 与普通错误均有出口。
- 选中文字 chip 最多两行省略，清除按钮有足够命中区，清除后焦点回输入框。
- 输入区为一体化容器（18px 圆角），textarea 与 Send 图标按钮同属一个组件；Enter 发送、Shift+Enter 换行、允许粘贴、冷却显示秒数。
- 保留焦点陷阱、Escape、关闭后焦点恢复与滚动锁定，并新增消息/发送状态自动滚动到底部。

### 2. 结果页与讲评弹层

- 成绩 Hero 改为石墨深底 + 青柠大分数，成为全页唯一主焦点；正确、待复核、迟交以简洁指标行呈现，状态使用现有 badge。
- 新增本地筛选「全部 / 错题 / 待复核」，显示各自数量与当前显示数量，只过滤现有 `result.answers`；空结果显示 EmptyState +「查看全部」。
- 答对题的「看讲评」降为 ghost 次级按钮；错题/待复核保留 primary。
- 待复核题分数旁显示「分数可能调整」。
- 讲评弹层分为「官方解析」（`answer.analysis` 存在时）与「AI 讲评」；AI 区固定边界文案「由 AI 生成，仅供学习参考。」；徽标只按真实 `engine`（`llm`/`template`）与 `degraded` 显示。
- `cleanPlainText()` 清理 `**`、`__`、反引号与行首 `#`，使用纯文本 `white-space: pre-wrap`，未使用 `v-html`，未引入 Markdown 依赖。
- 503 保留原地「重新生成」，不新建 attempt、不清空题目与答案上下文。

### 3. 学生表

- 表格 `min-width: 760px`，学号/姓名/状态/操作列设最小宽度，姓名 `white-space: nowrap`，操作按钮 nowrap。
- 375px 下容器局部横向滚动，首列吸附；页面本身无横向溢出；保留重置密码、停用/恢复、确认弹窗与归档只读。

### 4. 首页 / 成长 / 工作台 / 账号设置

- 学生首页仅「当前等级」为石墨＋青柠焦点卡，使用真实 `progress_pct/xp_to_next`；其余统计保持浅色，手机保持 2×2。
- 成长页仅等级区为石墨焦点卡；流水仅在合法 `attempt` 引用时出现「查看答卷」。
- 教师工作台保留四指标卡与结构，新增真实 `pending_review` 任务条（数量 + 去批改），比普通统计更醒目，未新增图表。
- 教师账号设置与学生「我的」内容区限宽 920px 居中，账号摘要紧凑，补改密规则说明；未展示任何无数据支持的设备、地点或上次改密时间。
- 两页错误均补内联「重试」，复用原 `load()`。

### 5. 可访问性

- 新增 icon-only 按钮均有中文 `aria-label`；关闭、清除、发送等命中区达标。
- 小芽键盘路径：打开、输入、Enter 发送、Escape 关闭、关闭后焦点回答题区；Tab 焦点限制在面板内。
- 新增筛选/任务条/快捷 chip 均有 `aria-pressed` 或可聚焦状态；`focus-visible` 使用现有 2px `lime-text` 轮廓。
- reduced-motion 沿用全局关闭无限动画与极短过渡；本轮未新增循环动画。
- 375/390/1440 均无页面横向溢出（学生表自身局部横滚除外）。

- **后端：未修改。** 本轮只改 `frontend-v3` 展示层。
