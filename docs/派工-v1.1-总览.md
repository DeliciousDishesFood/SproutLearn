## 三、执行顺序

1. **后端先冻结 AI 契约**：`ai-preview` 路由 + 文本抽取 + LLM 归一化 + 测试。
2. **前端并行做不依赖 AI 的项**：F1 文件选择器、F3 SVG 图标、F4 加载更多、
   F5 switch、F6 数字动效、F7 热力图、F8 工作台学生状态。
3. **AI 前端联调**：后端 `ai-preview` 可用后接 F2；未可用时先按 50301 降级态验收。
4. **主窗口最终验收**：typecheck/build、目标 pytest、截图、契约哈希、无新增依赖。
5. **大版本提交**：由主窗口统一 commit，前端/后端窗口不得自行 commit。
