### F1 对比度、焦点与文字下限（P0）

涉及：`src/design/tokens.css`、`src/design/base.css`、使用 `tertiary/small` 的组件。

1. `--tertiary:#9AA1AB` 不再承载时间、说明、表头等真实信息。真实辅助文字改 `muted` 或新增满足 4.5:1 的浅层级文字色；`#9AA1AB` 仅保留禁用/纯装饰。暗色同步检查。
2. 焦点不要只用 `#7CCE00` 淡光：统一 `2px solid var(--lime-text)` + `outline-offset:2px`，可保留浅色外层光，但轮廓本身清晰；按钮、链接、卡片选项、select、tabs、热力格、抽屉、弹窗全部覆盖。
3. 正文/表格主信息 13.5–14px；辅助信息 12px；除装饰外不低于 11px。数字继续 `tabular-nums`。
4. 交付一个无依赖 contrast 检查脚本或计算结果：正文/辅助文字 ≥4.5:1，大标题 ≥3:1，焦点轮廓与相邻色 ≥3:1。

### F2 BaseModal 与移动抽屉焦点闭环（P0）

涉及：`components/ui/BaseModal.vue`、新增 `composables/useFocusTrap.ts`、`layouts/AppShell.vue`。

- 弹窗 `aria-labelledby` 关联标题，`aria-describedby` 关联可选描述；记录触发元素；打开后聚焦首个可交互控件（无则标题/对话框）；Tab/Shift+Tab 不离开；Escape 关闭；关闭后恢复触发按钮；body overflow 还原原值。
- 抽屉复用同一 focus-trap：Escape、焦点圈定、关闭恢复、背景不可误 Tab；遮罩点击规则不变。
- 嵌套确认弹窗不能导致焦点恢复到已卸载节点；组件卸载时清理全部监听。
- 不接受只加 `aria-modal=true` 的形式修复。

### F3 BaseSelect / BaseTabs / 作答选项键盘语义（P0）

涉及：`BaseSelect.vue`、`BaseTabs.vue`、`student/AttemptView.vue` 及 tabs 使用处。

1. BaseSelect：每个 option 有稳定 id；触发器打开时设置 `aria-activedescendant`；活动项移动同步；`role=option`/`aria-selected` 完整；Home/End 跳过 disabled；Escape 返回触发器；鼠标与键盘选中结果一致。
2. BaseTabs：roving tabindex；左右/Home/End；`aria-controls` 关联面板，面板 `role=tabpanel`/`aria-labelledby`；导入弹窗两个 tab 实测。
3. 作答选项优先原生 radio/checkbox + label/fieldset/legend；原生 input 视觉隐藏但必须可聚焦，不能 `display:none`；Space 选择、radio 方向键可用；不改变现有视觉和自动保存。
4. 手机 scroll-snap 滑动停止后同步 `currentIndex`、题干与答题卡；用 `scrollend` 或 debounce fallback，避免与 `goTo()` 的平滑滚动递归。

### F4 危险确认与真实失败出口（P0）
