## 二、设计约束（必须遵守）

- 视觉：board-ui 青柠亮绿（`--lime` / `--lime-deep`），细边线、8–12px 圆角、表头弱底；

- 图标：统一 `lucide-vue-next` SVG；不新增图标库。

  的“筛选行 + 表格 + 分页”语言，但不抄 React/Tailwind 代码。

### F7. 热力图底部月份排版 + 状态组件

**文件**：`src/components/ui/HeatDots.vue`、`src/design/base.css`。

#### 月份 bug

旧逻辑只看 `index % 7 === 0` 的**列首日**：
12 周窗口从 8/24 开始，9/1 落在第 2 列中间，标签就跑到第 3 列；
`gridColumn: span 2` 还会让相邻标签重叠。截图里 8/9/10/11 月间距不均。

新逻辑：

1. 按列聚合：每列 7 天；找出该列**任意一天**所属月份。
2. 生成月份段：
```ts
type MonthSegment = { label: string; startCol: number; endCol: number }
```
   - 从第 0 列开始；一旦某列出现新月份，上一段 `endCol = col-1`，新段 `startCol = col`；
   - 最后一段 `endCol = weeks-1`。
3. 渲染：
```vue
<div class="heat-months" :style="{ gridTemplateColumns: `repeat(${weeks}, 1fr)` }">
  <span
    v-for="m in monthSegments"
    :key="m.startCol"
    :style="{ gridColumn: `${m.startCol + 1} / ${m.endCol + 2}` }"
  >{{ m.label }}</span>
</div>
```
   - 每个标签在自己的月份段内居中；不再 `span 2` 固定；
   - 8 月只占 1 列时也居中，不左漂。
4. 月份文本用 `Intl.DateTimeFormat('zh-CN', { month:'numeric' })` + `月`；
   跨年时标签仍正确；不硬编码 8/9/10/11。
5. 底部只保留月份轴；图例移到卡片头部右侧（`少—多`）或月份下方右侧，
   不要和 8 月标签挤在同一行。
6. 12 列 `< 400px` 时允许 `overflow-x:auto`，但 375 宽应尽量放下（cell 可缩到 8px）。

#### 状态组件

1. 悬浮/聚焦/点按某格时，读数条升级为 chip：
   - 左侧色点（对应该格 `level`）
   - 日期 + 星期
   - 值：教师 `作答 N 次 · 活跃 M 人`；学生 `+N XP · 作答 M 次`
   - 无记录：`无学习记录`
2. 保留 `aria-live="polite"`；键盘左右 ±7、上下 ±1 不变。
3. 不要重加原生 `title` 双提示。
4. 悬浮时格子有 `outline`/scale 1.05 的轻反馈，尊重 reduced-motion。

**验收**：
- 1440 热力图截图：8/9/10/11 月标签间距按月份段分布，无重叠；
- 375 热力图截图：不横向溢出；
- 悬浮/键盘读数 chip 截图各 1 张；
- P13 写出 12 周窗口的月份段数组（如 `[{8月,0,0},{9月,1,4},{10月,5,8},{11月,9,11}]`，以实际为准）。

2. **选中即生效**：`watch` 两个值直接重算/重拉，不出现“筛选”按钮。
3. 数据（不新增 endpoint）：
   - `papersApi.list(classId, { page:1, page_size:50 })` 取考试列表；
   - `classesApi.students(classId, { page, page_size:50 })` 循环取全量学生（最多 10 页）；
   - `papersApi.attempts(paperId, { page, page_size:50 })` 循环取该考试全部作答（最多 10 页）；
   - `Promise.all` 学生与作答；merge 按 `student_id`。
4. 状态映射：
   - 无 attempt → `未开始`
   - `doing` → `进行中`
   - `submitted` → `待复核`
   - `graded` → `已复核`
5. 表格列：`学生 / 学号 / 状态 / 得分 / 提交时间 / 操作`
   - 得分 `total_score / full_score`，无 attempt 显示 `—`；
   - 提交时间 `formatDateTime`，空显示 `—`；
   - 操作：`submitted` → `去批改`（`/teacher/attempts/{id}/result`）；
     `graded` → `查看`（同路由）；`doing` → `作答中`（不可点）；
     `not_started` → `—`。
6. 空态：
   - 没有考试：`还没有考试；发布一场考试后这里会出现学生状态。`
   - 该考试没有学生：`这个班级还没有学生。`
   - 状态筛选无结果：`没有符合「待复核」的学生。`
7. 分页：前端 `PaginationBar` 对 merge 后的行分页（page_size 10），不要每页发请求。
8. 竞态：
   - 切班：清空 `selectedExamId` + 行数据，重新 load exams；旧请求结果丢弃；
   - 换考试：同一请求序号守卫，旧响应不得覆盖；
   - 状态筛选只做本地 filter，不发请求。
9. 加载态：`BaseSkeleton` 2 行；错误 `notice notice--danger` + 重试按钮。
10. 不要拉 `GET /classes/{id}/attempts`（不存在）；不要新增 contract。
