## 五、风险

- **LLM 可用性**：全部 provider 失败/超时返回 50301「小芽暂时不可用，请稍后再试」；前端需兜底展示，不要把 503 当成业务答案。
- **限流降级**：Redis 故障时按契约降级放行，不阻塞练习；此时频控/日上限不生效。
- **日限窗口**：每日 40 次按自然日（服务器本地时区 `date.today()`）切窗，跨时区或夏令时边界可能存在 ±1 天偏差。
- **答案泄漏纵深**：当前在 prompt 构造层隔离 `answer_json/analysis`，模型输出侧无二次脱敏；若模型被诱导复述选项，依赖系统提示约束。
- **竞速超时**：整体等待上限由 provider timeout 控制（链路覆盖约 8 秒），慢 provider 不会阻塞首个可用回答。

## 联调信息（供前端窗口对照）

### 接口

- **路径**：`POST /api/v1/attempts/{attempt_id}/ask`
- **鉴权**：`Authorization: Bearer <学生 access token>`；`require_student` 校验，教师/未登录按既有鉴权返回 401/403。
- **Content-Type**：`application/json`

### 请求体

```json
{
  "question_id": 12,
  "selected_text": "TCP",
  "message": "为什么不是网络层？",
  "history": [
    { "role": "user", "content": "上一轮问题" },
    { "role": "assistant", "content": "上一轮小芽的引导" }
  ]
}
```

字段约束：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `question_id` | int | ≥1，必须属于当前试卷 |
| `selected_text` | string | 1–500 字，去空白后非空 |
| `message` | string | 1–500 字，去空白后非空 |
| `history` | array | 最多 6 条，超出截断为最近 6 条；单条 `content` ≤1000 字；`role` 仅 `user`/`assistant` |

### 成功响应（200，统一信封 `data` 内）

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "answer": "先回忆协议分层的概念，TCP 工作在哪一层，再结合题干自己想一想。",
    "sources": [
      { "doc_id": 7, "doc_name": "课程讲义.pdf" }
    ]
  },
  "request_id": "…",
  "timestamp": "2026-11-15 00:12:00"
}
```

`sources` 仅含 `doc_id`、`doc_name`，不回切片正文；无引用资料时为 `[]`。

### 错误码表

| HTTP | 业务 code | 触发条件 | message 示例 |
| --- | --- | --- | --- |
| 400 | 40001 | `selected_text` / `message` 为空或空白 | 问题不能为空 |
| 403 | 40301 | 试卷 `kind` 为 `exam` / `homework`，非练习模式 | 当前不是练习模式，小芽暂不开放 |
| 403 | 40302 | attempt 非本人或跨班 | 无权访问该作答记录 |
| 404 | 40401 | attempt 不存在 / 题目不属于该试卷 | 作答记录不存在 / 题目不属于该试卷 |
| 409 | 40910 | attempt 状态非 `doing`（已提交/已批改） | 本次作答已结束，小芽暂不开放 |
| 429 | 42901 | 3 秒频控命中，或今日提问超过 40 次 | 操作过于频繁，请 3 秒后再问 / 今日提问次数已达上限，请明天再来 |
| 503 | 50301 | LLM 全部 provider 失败或超时 | 小芽暂时不可用，请稍后再试 |

### 联调备注

- 前端只上送最近 6 条 history 即可，后端会再次截断兜底。
- `answer` 已在后端完成 Markdown / LaTeX / 代码围栏清理，为纯文本；前端按纯文本渲染。
- 限流按学生身份维度，不按题目或班级。
