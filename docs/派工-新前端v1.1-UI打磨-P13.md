## 1. 结论

F0–F10 全部按派工包实现，`npm run typecheck` 与 `npm run build` 均 **exit 0**。

- 题库导入已完全去掉可见的原生 file input：点击 / 拖拽 / 键盘（原生 button 支持 Enter/Space）+ 文件 chip + 20 MB 内联校验 + 格式 chips + CSV 模板下载。
- 导入弹窗新增「模板导入 / AI 智能识别」双 tab；AI 调 `POST /questions/import/ai-preview`，展示共 N / 可导入 M / 异常 K、`AI 识别` badge、engine/model、degraded、warnings、前 6 题摘要、错误列表、截断提示；50301 / 42901 / 42203 / 40001 分别处理，50301 与 42203 提供「切换到模板导入」。

- 新增 `countUp` + `CountUpNumber`，工作台 4 张统计卡与热力图 4 项统计从 0 滚到终值，字符串 `78%` 保持静态。

- 组卷原生 checkbox 换成 `BaseCheckbox`（隐藏 input + SVG 方块，整行可点、Space 可勾选）。

## 4. 未做项 / 未验证项

1. **真实 ai-preview 后端**未联调（后端窗口并行实现中）；本窗口仅按契约类型与错误码实现，未伪造真实 LLM 调用。
2. **42901 / 42203 / 40001** 仅实现分支与文案，未用真实后端响应验证。
3. **>50 条分页**：学生与 attempts 各最多循环 10 页（500 条），未在更大数据量下验证。
4. **自动加载**：F4.3 的 IntersectionObserver 为可选，本轮只做“滚到底 + 点击加载更多”fallback；未做自动翻页。
5. **125% / 150% 系统缩放**：只按 100% DPR 计算了 `.switch` 几何值（上下间隙 2px），未在真实缩放环境复测。
6. **prefers-reduced-motion**：代码路径已处理（countUp 直显、热力 hover 不缩放），未在真实系统“减少动态效果”下截图。
7. **暗色主题**：主题系统未改，但本轮 17 张截图均为亮色，未逐页复验暗色。
8. **Firefox / Safari / 真机触屏**未测；学生状态表在 375 采用“容器内横向滚动”方案（已在 §3.3 #12 说明）。
9. **CSV 模板的 options 示例格式**（`A.def|B.func|...`）未与后端真实解析器联调确认。
10. 后端 `ai-preview` 的 `max_questions` 上限（100）未做成前端可调项，固定默认 50。

## 5. 风险

1. AI 预览依赖后端文本抽取与 LLM 稳定性；503/429 时用户需手动切模板，未做自动重试（按契约不自动重试）。
2. 学生状态聚合受 10 页上限约束：单班学生 >500 或单考试 attempts >500 时会缺行；正常班级规模内无影响。
3. 月份标签为“单列段也居中”允许溢出 13px 列宽，极窄容器（<300px 卡片内容宽）下相邻标签有理论重叠风险；375 实测无问题。
4. 375 学生状态表需横向滑动查看得分/时间/操作列，可读但不便；后续若需要可改卡片化。
5. 组卷题库首次加载 50 题，128 题需两次手动“加载更多”；未做自动加载以减少误触与请求。
6. 截图证据基于契约夹具，不能替代真实后端联调结论。
