## 结论

2026-11-17，开发环境的登录 500 已修复。根因是宿主机 `backend/` 挂载到 API 容器后，v1.4 ORM 代码已由 `--reload` 加载，但 MySQL 仍停在 Alembic `0010_bot_teacher_ai`，导致登录查询 `teacher.auth_version` 时数据库报 1054。
