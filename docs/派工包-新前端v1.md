### 2.3 HTTP 客户端（F0 必做）

`src/api/client.ts` 必须满足：

1. `baseURL = import.meta.env.VITE_API_BASE_URL ?? '/api/v1'`。
2. 请求拦截：有 token 时加 `Authorization: Bearer <token>`。
3. 响应拦截：`code === 0` 返回 `data`；否则抛 `ApiError`。
4. `ApiError` 含 `code / message / data / request_id / http_status`。
5. `40101/40102` 清 `localStorage` 的 token/user，广播 `auth:expired`，由 router 跳登录；登录页请求设置 `skipAuthRedirect`。
6. 网络错误统一 `{ code: -1, message: '网络异常，请检查后端是否启动' }`。
7. 不把后端 `message` 吞掉；表单页展示后端原文。
8. 支持 `skipGlobalError`，页面自己接管错误态。

## §5 功能细节（F1–F6）

### 5.1 登录与路由

- `POST /auth/login` 成功后存 token + user；再 `GET /auth/me` 补全 user。
- 学生 `class_id` 用于后续 `GET /classes/{class_id}/papers`；教师没有 `class_id`，从 `GET /classes` 选当前班。
- 路由守卫：`meta.role` 为 `teacher/student/public`；角色不符跳自己的首页并 toast。
- 退出：`POST /auth/logout`（失败也清本地），清 store，跳登录。

### 5.2 教师工作台

- `GET /classes` 为空 → 创建班级空态，不请求 workbench。
- 有班级：默认第一个班；顶部可切班。
- “待复核题目”= `pending_review`，文案必须写“道/题”，不写“份”。
- 平均得分率：`average_score_rate` 0~1 → 百分比；`average_score` 只在 tooltip/详情写“原始平均分”。
- 最近试卷用 `PaperBrief`，不要读 `class_id/blank_mode/shuffle`；`due_at` 可能 `null`，显示“未设置截止”。
- 热力用 `activity`，日期 `YYYY-MM-DD`；空数据画 `heat-0` 点阵，不显示假数。

### 5.3 班级/学生

- 创建班级 `{ class_name, course_name }`；返回 `invite_code` 展示并可复制。
- 学生表格字段：学号、姓名、等级、XP、QQ 绑定、最近登录；搜索 `keyword`，分页。
- 邀请码：显示当前码/过期时间；重置要二次确认；重置后旧码失效。

### 5.4 知识库

- 上传 multipart：`class_id`、`course_name`、`files[]`；支持多文件。
- 结果必须展示 `success_list` 与 `fail_list`；部分失败不报整体失败。
- 状态：0 待处理 / 1 解析中 / 2 可预览 / 3 失败；失败显示 `error_message`，不要只显示“失败”。
- 删除要二次确认。

### 5.5 题库/题目

- 题库空 → 引导新建；删除前检查 `question_count`，非空后端会 `40912`。
- 导入：preview 拿 `token` + 预览行；commit 传 `{ token, rows?, bank_id? }`；不要把 preview 结果直接当已入库。
- 题目筛选：`bank_id/type/tag/difficulty/status/keyword`；分页。
- 编辑弹窗保存 `PATCH /questions/{id}`；删除二次确认。
- 讲评：普通接口取 `explanation ?? content`；流式接口按 SSE `meta/delta/done` 拼接，失败回退普通接口。

### 5.6 试卷/组卷

- 组卷两种：固定题目 `question_ids`；随机抽题 `bank_ids + knowledge_tag/difficulty/count`；两者不要同时空。
- 字段：`title/mode/kind/duration_minutes/shuffle/blank_mode/due_at`；`kind` 默认 practice，考试/作业明确选择。
- 发布前确认；`POST /papers/{id}/publish` 返回 `group_notice`，`failed` 提示“群通知失败，但试卷已发布”。
- 已发布不可改内容；撤回 `PATCH /papers/{id}/withdraw`；撤回后学生列表不再显示。
- 教师详情 `GET /papers/{id}` 才含答案/解析；学生详情禁止调用。
- 到期时间 `due_at` 与单次倒计时 `deadline_at` 分开展示。

### 5.7 作答/练习

- 学生开卷：先 `POST /papers/{id}/attempts`，拿 `AttemptDetail`；已有 attempt 幂等返回。
- 恢复：`GET /attempts/{id}`，`answers` 是按 question_id 字符串的 map；渲染时逐题取。
- 自动保存：选项点击/文本 blur 后 500ms debounce；保存中显示“保存中”，成功“已保存”，失败“保存失败，重试”；不阻塞切题。
- 计时：`remaining_seconds=null` 显示“不限时”；`0` 显示“已截止”，禁用输入并提示提交/退出。
- 提交：二次确认；`POST /submit` 幂等；成功后跳结果页；`40910` 表示已提交，直接跳结果。
- 结果：学生只在 `submitted/graded` 调 `GET /result`；若后端未修 B0，前端也**不得在 doing 调结果**。
- 逐题：`is_correct`、`score`、`standard_answer`、`analysis`、`needs_review`；待复核显示“待老师复核”，不要显示 0 分定论。
- 讲评按钮：`POST /questions/{id}/explain`，带 `student_answer`；失败保留原结果。

### 5.8 问问小芽

- 仅在 `paper.kind === 'practice'` 且 `attempt.status === 'doing'` 渲染入口。
- 选区范围：题干容器 + 选项容器；忽略 `input/textarea/contenteditable`；2–300 字才显示浮动按钮。
- 点击后：把选中文本作为 chip；输入框预填 `关于我选中的“{text}”，`，光标置尾；**不自动发送**。
- 请求：`{ question_id, selected_text, message, history }`；history 只带最近 6 条。
- 响应：`answer` 纯文本；`sources` 渲染为文档名 tag；`sources` 空不显示。
- 失败：`42901` 显示“问得太快，3 秒后再试”并禁用；`50301` 显示“小芽暂时不可用”+ 重试；不自动重试。
- 关闭：Esc/点外/切题关闭；关闭后焦点回答题区；移动端不遮提交栏。

### 5.9 通知/文档/设置

- 通知列表 `items` + `unread_count`；read 单条/全部；未读 badge。
- `target_path` 映射：
  - `/student/papers/{paper_id}` → `/student/papers?paper={paper_id}`
  - `/student/attempts/{attempt_id}/result` → `/student/attempts/{attempt_id}/result`
  - `/student/notifications` → `/student/notifications`
  - 未知路径 → `/student/notifications`，不能 404。
- 文档：`GET /docs` 目录；`GET /docs/{slug}` 正文；`content ?? markdown`；用 DOMPurify 清洗后再渲染；无 Markdown 就按纯文本。
- 机器人：`app_id` 必填；Secret 不在前端输入；展示 `secret_managed_by_env` 文案；测试按钮给 `ok/message`；绑定码显示倒计时。
- XP：`GET/PATCH /classes/{id}/xp-config`；`items` 与 `list` 同值，取 `items ?? list`；保存逐项。
