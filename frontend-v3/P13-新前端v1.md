## 五、风险

- **环境口径风险**：本轮跑在 8010 的 SQLite 种子库 + fakeredis，不是生产 MySQL；`/health` 返回 503/50301 是 MySQL 探针无库所致，与业务无关。切生产库后可能暴露字段缺失、索引或数据口径差异，需复测。
- **LLM 依赖风险**：ask 成功链路与 sources 引用样式依赖后端 LLM 服务部署；当前仅错误态可用，上线前必须补成功问答、超时与 429 文案验证。
